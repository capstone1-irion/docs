# 인터페이스 명세 작성 기준

현재 합의된 실행용 스키마는 없습니다. 임시 스키마는 임시임을 명시하고 각 파트가 검증한 뒤 확정합니다.

## Telemetry → AI

| 확인 항목 | 기록할 내용 |
| --- | --- |
| 입력 출처 | MAVLink 메시지와 실제 필드, 사용 PX4·디코더 버전 |
| 의미·단위 | 물리적 의미, 단위, 변환 방법, 명령/모사 상태 구분 |
| 시간 | 기준 시계, 타임스탬프 단위, 실제 갱신 주기와 정렬 |
| 식별 | 배터리 ID, 모터 인덱스와 Motor 1~4 대응 |
| 유효성 | 미제공·unknown·센티넬·결측·비정상 수치 처리 |
| 전처리 | 학습/실시간 공통 처리, 미래 데이터를 사용하지 않는 방식 |

## AI → UI

| 확인 항목 | 기록할 내용 |
| --- | --- |
| 판단 | 정상/이상/판단 불가 상태 표현 |
| 구간 | 이상 시작·종료 시각과 시간 기준 |
| 대상 | 배터리 또는 모터별 식별자, 식별 방법 |
| 점수 | 필요 시 모델 내부 점수·임계값의 의미 |
| 전송 | 선택한 전송 방식, 엔드포인트/포트, 주기, 연결 실패 처리 |

정답용 이상 주입 설정은 배포 가능한 AI 입력과 분리합니다.
