# 통합 시연과 검증 기록

## 필수 시나리오

- [ ] 정상 비행: 데이터 생성부터 AI 판단과 UI 표시까지 확인
- [ ] 배터리 이상: PX4 상태 반영, MAVLink 수집, 경고 시간/구간·대상 확인
- [ ] 모터 이상: 모터 식별, MAVLink 수집, 경고 시간/구간·대상 확인

## 시나리오별 기록

- 관련 소스 버전과 실험 설정
- 비행 조건과 이상 주입 방법, 정답 시간/구간
- 텔레메트리 및 모델 입력의 유효성
- 실행 명령, 실제 결과와 미검증 항목
- 오탐·미탐과 Detection Delay 등 정의한 지표

위 목록은 완료 기준이며 실행 완료를 의미하지 않습니다. 고정값 통신 검증과 동적 상태 모델 검증을 구분합니다. 단순 표시값 변경인지 기체 물리에도 영향을 주는 이상인지 명시합니다.
